The **Open Course Space** gives one course or many an open home on the web, managed from one site. Each course has its own pages, header image, sidebar and footer, and content can be shared between courses with the [Page Inject Plugin](https://github.com/getgrav/grav-plugin-page-inject). Everything is stored as simple Markdown files you control – learn more in the [README on GitHub](https://github.com/hibbitts-design/grav-skeleton-open-course-space#readme).
